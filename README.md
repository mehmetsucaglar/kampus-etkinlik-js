# 🎓 Kampüs Etkinlikleri (Sprint 3)

Üniversite kampüsündeki etkinliklerin listelenmesi, yönetilmesi ve dinamik olarak takip edilmesi amacıyla geliştirilen **Kampüs Etkinlikleri** web uygulaması.

---

## 🚀 Proje Hakkında

Bu proje, kampüsteki kulüp ve öğrenci etkinliklerinin web üzerinden kolayca görüntülenmesini, filtrelenmesini ve yeni etkinliklerin eklenmesini sağlayan etkileşimli bir web arayüzüdür. **Sprint 3** aşamasında, arayüze dinamizm katmak adına JavaScript entegrasyonu gerçekleştirilmiştir.

---

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Sayfa yapısı ve anlamsal (semantic) etiketler (`header`, `nav`, `main`, `section`, `footer`).
- **CSS3:** Modern ve responsive (duyarlı) grid/flexbox sayfa düzeni ve stil yapılandırması.
- **JavaScript (ES6+):** Form validasyonları, etkinlik listeleme, dinamik DOM manipülasyonu ve filtreleme/etkileşim mekanizmaları.
